# books (monorepo)

This repository is organized as a monorepo and contains multiple example projects and starter kits.

## Packages

- `book1-portfolio` — A portfolio starter project that demonstrates building a personal website and project showcase, with practical examples and templates.
- `book2-atopbank` — A sample banking app tutorial and reference implementation focused on backend design patterns, security, and transaction flows.
- `starter-kits` — A collection of small starter templates and utilities to bootstrap projects quickly (frontend, backend, configs).

## Getting started

This repo can be used with JavaScript/TypeScript workspace tooling (Yarn workspaces, PNPM, or npm) if desired; a root `package.json` is provided to enable workspace features.
