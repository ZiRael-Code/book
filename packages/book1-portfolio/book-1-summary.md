# Part 1 — HTML: The Foundation

(Chapters 1–11)

You learned:

- What HTML actually is
- How browsers read tags
- The difference between structure and styling
- Block vs inline flow
- Lists and navigation
- Images and semantic meaning
- Forms and tables
- Proper document architecture

By the end of the HTML section, you could:

- Build a complete semantic portfolio skeleton
- Structure a header, nav, main, sections, and footer
- Create accessible forms
- Use alt text correctly
- Organize content intentionally

You were no longer guessing.

You understood structure.

- Responsive design
