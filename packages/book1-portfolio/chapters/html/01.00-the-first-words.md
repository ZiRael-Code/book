# Part 1 — What HTML Actually Is

HTML stands for **HyperText Markup Language**.

Important:  
HTML is not a programming language.

It does not:
- calculate
- loop
- make decisions

HTML describes structure.

It tells the browser:

- this is a heading
- this is a paragraph
- this is navigation
- this is the main content

Think of HTML as the skeleton of a website.

CSS will later control appearance.  
JavaScript will later control behavior.

Right now, we build structure.

---

# Part 2 — Tag Anatomy

Everything in HTML is built using **tags**.

Most tags follow this structure:

```html
<tagname>Content</tagname>
```

Example:

````
<p>Hello world</p>
````

- <p> is the opening tag
- </p> is the closing tag
- The text in between is the content

The slash / means closing.

If you forget to close tags, browsers try to fix your mistake.
Sometimes they guess wrong.

We do not rely on guessing.

---

## Void Elements (Self-Closing Elements)

Some tags do not wrap content.

Example:

```html
<meta charset="UTF-8">
```
There is no closing `</meta>`.

Other examples you’ll see later:
- `<img>` for images
- `<br>` for line breaks
- `<link>` for CSS files

These are called void elements.

---

## Nesting (Parent and Child)

Tags can live inside other tags.

Example:
```html
<body>
  <h1>John Doe</h1>
</body>
```
`<body>` is the parent.
`<h1>` is the child.

Indentation does not affect the browser.
It affects humans.

Clean structure matters.

# Part 3 — The Boilerplate (The Real Page Foundation)

Every proper HTML page begins with this structure.

Open your index.html.

Replace everything with:
```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>John Doe — Developer Portfolio</title>
  </head>

  <body>
  </body>
</html>
```

Save the file.

Now let’s understand it.

`<!doctype html>`

This tells the browser:

“This is modern HTML5.”

Without it, browsers can enter “quirks mode.”
That causes weird layout behavior.

Always include it.

`<html lang="en">`

This wraps the entire page.

`lang="en"` tells:

- screen readers
- search engines

what language the page uses.

Accessibility starts here.

---

# Part 4 — `<head>` vs `<body>`

This is critical.

`<head>`

The head contains invisible information.

It includes:

- encoding rules
- page title
- metadata
- links to CSS (later)

Nothing inside `<head>` appears visually on the page.

`<body>`

The body contains everything the user sees:

- headings
- text
- images
- links
- sections

If it appears on the screen, it lives in `<body>`.

`<meta charset="UTF-8">`

This defines character encoding.

Without it, special characters can break.

Always include it.

`<title>`

The title appears:

- in the browser tab
- in search results
- in bookmarks

It does NOT appear inside the page itself.

Change it and refresh your tab.
You’ll see it update instantly.

# Part 5 — Headings & Paragraphs

Now we begin building real content.

Inside your `<body>`, add this:

```html
<body>
  <h1>John Doe</h1>
  <p>Full-Stack Developer</p>
  <p>I build clean, modern, and user-focused web experiences.</p>
</body>
```

Save.
Refresh your browser.

You just created your first real portfolio section.

---

## Understanding Headings

Headings go from `<h1>` to `<h6>`.

**Rules:**

- Use only one `<h1>` per page.
- Headings define structure, not size.
- Do not choose them because they “look big.”

Your `<h1>` is your identity on this page.

---

## Understanding Paragraphs

Paragraphs wrap blocks of text.

Pressing Enter alone does nothing in HTML.

Structure comes from tags.
