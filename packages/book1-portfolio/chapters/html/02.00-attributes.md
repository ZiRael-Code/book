# Part 1 — What Attributes Are

In Chapter 1, we learned:

```
<tagname>Content</tagname>
```

Attributes live inside the **opening tag**.

Structure:

```
<tagname attribute="value">Content</tagname>
```

Example:

```
<html lang="en">
```

Here:

- `lang` is the attribute
- `"en"` is the value

Attributes give extra information about an element.

Without attributes, tags are basic.

With attributes, they gain meaning.

### Quoted Values

Attribute values **must** be wrapped in quotes.

Correct:

```
<a href="about.html">
```

Incorrect:

```
<a href=about.html>
```

**Always use quotes.**

## Part 2 — Core Attributes

### `class`

`class` is used to group elements for styling later.

Example:

```
<p class="subtitle">Full-Stack Developer</p>
```

Right now, nothing changes visually.

But later, CSS will target this class.

Think of `class` as a label you attach for styling.

### `id`

`id` is a **unique identifier**.

Example:

```
<h1 id="hero-title">John Doe</h1>
```

Important rules:

- An `id` must be unique.
- Only one element should have a specific `id`.

Later, we will use `id` for navigation and linking.

## Part 3 — Link Attributes (`href`)

Now we introduce the anchor tag:

```
<a>Link</a>
```

On its own, it does nothing.

It needs `href`.

Example:

```
<a href="#contact">Contact Me</a>
```

`href` tells the browser where to go.

It can point to:

- another page
- a section on the same page
- an external website

Example (external):

```
<a href="https://github.com">My GitHub</a>
```

**Without `href`, it is not a real link.**

## Part 4 — Image Attributes (`src`, `alt`)

Images use the `<img>` tag.

It is a **void element**.

It does not wrap content.

Basic structure:

```
<img src="image.jpg" alt="Description">
```

### `src`

`src` means **source**.

It tells the browser where the image lives.

Example:

```
<img src="assets/profile.jpg" alt="Portrait of John Doe">
```

The browser looks inside the `assets/` folder.

If the path is wrong, the image breaks.

### `alt`

`alt` means **alternative text**.

This is **critical**.

It:

- describes the image for screen readers
- appears if the image fails to load
- improves accessibility

Never leave `alt` empty unless the image is decorative.

Good example:

```
<img src="assets/profile.jpg" alt="Portrait of John Doe smiling">
```

Bad example:

```
<img src="assets/profile.jpg" alt="image">
```

**Be descriptive and meaningful.**

---

## Why Attributes Exist

Attributes allow HTML to:

- connect pages
- identify sections
- describe media
- prepare for styling
- improve accessibility

Without attributes, HTML would be static and isolated.

**Attributes give it relationships.**

## Project Milestone — Add Link + Image to Hero

Now we upgrade your Hero section.

Inside `<body>`, update your content to:

```
<body>
  <h1 id="hero-title">John Doe</h1>
  <p class="subtitle">Full-Stack Developer</p>
  <p>I build clean, modern, and user-focused web experiences.</p>

  <a href="#contact">Contact Me</a>

  <img src="assets/profile.jpg" alt="Portrait of John Doe">
</body>
```

Save.

Refresh your browser.

If the image does not appear, make sure:

- you placed an image inside `assets/`
- the file name matches exactly

You now have:

- an `id`
- a `class`
- a working link
- a proper image with `alt` text

**Your portfolio just gained real meaning.**
