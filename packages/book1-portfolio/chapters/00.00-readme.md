## Explanation (Project setup, step-by-step)

Before we write any “real” HTML, we need a place to keep our work organized.

If you scatter files around your Desktop or Downloads folder, two things will happen:

1. You won’t be able to find anything later
2. Your project will become messy the moment you add images and CSS

So we start the same way real developers start:

**One folder for the whole project.**

---

### Step 1 — Create the main project folder

Create a new folder anywhere you can find easily. Good options are:

- Desktop
- Documents
- A folder called `Projects`

Name your folder:

`book1-portfolio`

This folder is the “container” for everything you will build in this book.

---

### Step 2 — Open the folder in VS Code

Now open VS Code.

1. Click **File**
2. Click **Open Folder...**
3. Select your `book1-portfolio` folder
4. Click **Open**

From now on, every file you create must be inside this folder.

If you don’t open the folder first, VS Code will still let you write code — but your files will end up in random places.

---

### Step 3 — Create the starter folders

Inside VS Code, look at the left sidebar. This is the **Explorer** (your project file list).

1. Right-click inside the Explorer area
2. Click **New Folder**
3. Create a folder named:

`assets`

Do the same again and create:

`styles`

What these folders are for:

- `assets/` will hold images, icons, and any files you use on the site
- `styles/` will hold CSS files (styling) later

We are not styling anything yet — but we are preparing the structure.

---

### Step 4 — Create your first file: `index.html`

Still inside the book1-portfolio folder in the Explorer:

1. Right-click
2. Click **New File**
3. Name it:

`index.html`

This will be the main page of your portfolio.

When you open a website, the browser needs an entry point.
For simple websites, `index.html` is the default entry file.

---

### Step 5 — Put a “starter page” inside `index.html`

Click `index.html`, then paste this code:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My Developer Portfolio</title>
  </head>
  <body>
    <h1>My Portfolio</h1>
    <p>This book is teaching me how to build this site.</p>
  </body>
</html>
```
Don’t worry if you don’t understand every line yet.  
This is just a clean starting point so your browser can open a real page. We will break it down properly in Chapter 1.

You should see:

- “My Portfolio” as a big heading
- one short paragraph below it

If you see that, your setup is correct.
