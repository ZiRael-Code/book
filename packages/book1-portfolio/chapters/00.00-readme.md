## 2. The Toolbox (What You Need)

Before writing code, let’s understand the tools at a basic level.

### A. VS Code (Your Editor)

VS Code is where you will:

- Create folders
- Create files
- Write HTML
- Organize your project

It’s your main working environment.

---

### B. Your Browser (The Renderer)

Your browser runs HTML.

When you open an `.html` file, the browser:

- Reads the tags
- Builds the page structure
- Displays the result visually

This is how your code becomes a visible webpage.

---

### C. Your File System (The Project Folder)

A real project is not a collection of random files.

Everything lives inside one main folder with a clear structure.  
Keeping your files organized now will prevent confusion later.

---

## 3. The Workshop (Project Setup)

You will create one project and expand it throughout the book.

---

### Step 1 — Create the Main Project Folder

Create a folder somewhere easy to find, such as:

- Desktop
- Documents
- A dedicated `Projects` folder

Name it:

```txt
book1-portfolio
```

This folder will contain everything for Book 1.

### Step 2 — Open the Folder in VS Code

In VS Code:

- Click **File**
- Click **Open Folder**
- Select `book1-portfolio`
- Click **Open**

**Important:**  
Always open the main project folder in VS Code.  
If you edit files outside the folder, your project can quickly become disorganized.

---

### Step 3 — Create the Starter Structure

Inside the VS Code Explorer (left sidebar), create two folders:

```text
assets
styles
```

**What they are for:**

- `assets/` → images, icons, documents (later)
- `styles/` → CSS files (later)

Creating this structure now keeps your project clean and scalable.

# Part 1 — The Code (Your Starter Page)

## 4. Create Your First HTML File

Inside `book1-portfolio`, create a file named:

### Why `index.html`?

Most web servers and browsers treat `index.html` as the default home page.

---

### Paste This Starter HTML

Open `index.html` and paste the following:

```
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My Developer Portfolio</title>
  </head>

  <body>
    <h1>My Portfolio</h1>
    <p>This book is teaching me how to build this site.</p>
  </body>
</html>
```

Save the file.

---

## 5. The Workshop Test (Open in Browser)

Now confirm everything works.

### Step 1 — Open the File

Locate `index.html` on your computer and double-click it.

It should open in your default browser.

### Step 2 — Verify What You See

You should see:

- **My Portfolio** (a large heading)
- A short paragraph below it

If you see both, your setup works correctly.

You're ready for Chapter 1.

You completed three real developer actions:

A portfolio is not a single file.
